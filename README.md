# 库管 · 仓库管理系统

一个开箱即用的中文多仓库管理应用。使用 Node.js 内置 HTTP 服务与 SQLite，前端采用原生 JavaScript，无需下载第三方依赖。

## 启动

安装 Node.js 24 或更新版本，在项目目录运行：

```sh
npm start
```

浏览器访问 http://localhost:3000。开发时可运行 `npm run dev` 自动重启后端。

Windows PowerShell 如果限制 npm 脚本执行，可使用 `npm.cmd start` 或 `node server.js`。

## 下载发布包

在 [GitHub Releases](https://github.com/Handsome-LS/KUGUAN/releases) 下载 `KUGUAN-v1.0.0.zip`，解压后运行。需要先安装 Node.js 24 或更新版本；不需要安装 npm 依赖。

- Windows：双击 `start.cmd`，保持启动窗口打开，然后访问 http://localhost:3000。
- macOS / Linux：在解压目录执行 `node server.js`，然后访问 http://localhost:3000。
- 首次运行会自动建立本地数据库与演示数据；发布包不包含开发者的数据库。
- `SHA256SUMS.txt` 包含 ZIP 的 SHA-256 校验值，可用于验证下载完整性。

开发者在 Git 工作区没有未提交改动时运行 `npm run package`，即可将当前提交打包到 `dist/` 并生成校验文件。打包需要 Git，运行发布包不需要 Git。

## 已实现

- 工作台概览：库存统计、各仓库库存分布、今日流转与最近动态。
- 物品档案：唯一物品编号、名称、分类、计量单位、预警线。
- 两种库存状态：数量大于零为「存在」，数量为零为「不存在」；按所选仓库计算。
- 加入：指定物品、仓库、数量、生产地 / 来源及可选备注。
- 消耗：填写数量与必填备注，库存不足时禁止操作。
- 调拨：选择来源仓库和目标仓库，同一数据库事务内扣减和增加，任一步失败均回滚。
- 仓库与管理员：新建仓库、指定负责人、添加管理员、切换当前操作人。
- 操作记录：保存操作人、时间、来源、去向、数量和备注，可查看详情、筛选与导出。
- 库存清单：搜索、仓库与分类筛选、状态筛选、低库存提醒、分页、排序、勾选导出。
- CSV 导出：UTF-8 BOM，可直接用 Excel 打开，并对公式前缀进行转义。
- 响应式布局：桌面侧栏、移动端抽屉、可横向滚动的库存表格。

数量使用正整数。低库存是提醒，不是第三种状态。新建物品档案不直接修改库存，后续通过加入操作录入，使每一份库存变动都可追溯。

## 数据与使用范围

首次运行自动创建 3 个仓库、3 位管理员、12 种物品及示例流转记录，方便体验。数据保存在 `data/warehouse.sqlite`，页面刷新和服务重启均不会丢失，也不会重复导入示例数据。

这是本地协作版本：管理员是负责人和操作人档案，不包含密码登录、身份验证或角色权限隔离。默认仅监听本机 `127.0.0.1`。切换操作人后，后续记录会保留该成员姓名。

停止服务后备份整个 `data/` 目录即可保留库存及历史记录。数据库文件不纳入 Git。

可使用环境变量 `PORT` 更改端口，使用 `DATABASE_PATH` 指定其他数据库路径。例如在 PowerShell 中：

```powershell
$env:PORT = '3001'
node server.js
```

## 验证

```sh
npm test
```

测试覆盖加入、归零、库存不足、调拨库存守恒、事务失败回滚、数据校验、文件持久化及 HTTP 接口。测试使用独立数据库，不会改动正常使用的数据。

已安装 Chrome 或 Edge 的 Windows 环境，还可运行 `npm run test:browser`，执行真实浏览器中的表单、导航、筛选、导出和移动端检查。其他安装位置可通过 `CHROME_PATH` 指定。截图与报告保存在 `test-results/`，浏览器检查使用独立的内存数据库。

## 项目结构

```text
server.js              HTTP 服务、静态文件与 API
lib/database.js        SQLite 表结构、业务规则与事务
public/index.html      页面入口
public/app.js          界面、表单、筛选、导出
public/styles.css      响应式样式
test/warehouse.test.js  业务及接口测试
data/                  首次运行自动创建的本地数据
```
